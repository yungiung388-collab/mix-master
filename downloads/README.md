# 실행용 ZIP

[실행용 ZIP 다운로드](mix-master-studio.zip?raw=true)

압축을 푼 뒤 Node.js 24.5 이상이 설치된 컴퓨터에서 실행하세요. Windows는 `start-windows.cmd`, macOS/Linux는 폴더에서 `sh start.sh`를 사용합니다. 빌드 결과를 포함하므로 실행만 할 때는 별도 npm 설치가 필요하지 않습니다.

휴대폰에서 쓰려면 이 앱의 Node 서버를 HTTPS 호스팅에 배포해야 합니다. ZIP 파일은 설치·실행용이며 모바일 웹 주소를 대신하지 않습니다. 사진 분석에는 서버에 `MIX_MASTER_AI_KEY`를 설정해야 합니다.
